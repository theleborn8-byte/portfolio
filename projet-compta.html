Site Web de Comptabilité

Ce projet a consisté à développer une interface web dédiée à la gestion économique complexe.

Créé avec Python et utilisant une base de données SQLite, cet outil permet de centraliser et d'automatiser les processus comptables liés à la gestion financière d'une communauté roleplay de grande envergure. Il inclut le suivi des transactions, la gestion de trésorerie et la structuration des données corporatives.
