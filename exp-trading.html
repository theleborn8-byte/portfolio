ALGORITHME
TRADING IA

Entre 2020 et 2022, je me suis lancé dans la création d'une startup axée sur l'Intelligence Artificielle. L'objectif était de développer un robot de trading autonome basé sur le Deep Learning. J'ai personnellement codé l'architecture racine du projet, intégrant une logique métier complexe et une interface de monitoring web.

Cependant, en Machine Learning, un algorithme sans données structurées n'est qu'une coquille vide. Sans accès aux documents financiers colossaux (datasets) nécessaires pour entraîner le réseau neuronal, l'IA ne pouvait pas "apprendre". Pour acquérir ces données de qualité institutionnelle, un financement majeur était indispensable.

Je me suis alors lancé dans une prospection acharnée, contactant plus de 60 000 investisseurs potentiels. Mais dans le contexte économique gelé par la pandémie de COVID-19, lever des centaines de milliers d'euros relevait de l'impossible. Une seule réponse favorable s'était enfin détachée, promettant de débloquer le projet. Tragiquement, cet unique partenaire financier a été emporté par la maladie avant la conclusion de l'accord. Cette expérience a forgé une résilience entrepreneuriale inébranlable et une compréhension lucide des limites techniques de l'IA.

Spécifications techniques

Stack : Python (Core IA) // Java // HTML & CSS (Dashboard) // Deep Learning
