Site Web Jeu du Killers

Application web développée pour digitaliser et encadrer les règles du célèbre jeu "Le Killer".

L'interface permet d'attribuer les cibles, de valider les contrats et de suivre la progression des participants en temps réel. Le défi principal de ce projet a été de concevoir une architecture logique robuste pour éviter les boucles fermées prématurées entre les joueurs.
